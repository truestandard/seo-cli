## [0.1.0] - 2026-08-28

### Added

- `seo login`, `seo projects`, `seo use`, `seo project show|create`
- `seo context get|set|add-competitor|add-page|log`
- `seo keywords list|add|update|remove`
- `seo research`, `seo serp`, `seo floor`
- `seo track run|status`, `seo ranks --since`
- `seo prompts list|add`, `seo ai run|results|status`
- `seo backlinks --history --months --rows`, `seo domain`, `seo mentions`
- `seo audit run|show|list`
- `seo gsc import|striking`
- `seo ship`, `seo experiments list|add|outcome`, `seo log`
- `seo scoreboard`, `seo spend`, `seo estimate`
- `seo mcp`: stdio MCP server that proxies every tool the backend serves
- Global `--json`, `--project`, `--dry-run`, `--base-url`
- Config in `~/.config/seo/config.json` with `SEO_BASE_URL`, `SEO_TOKEN`, `SEO_PROJECT` overrides
